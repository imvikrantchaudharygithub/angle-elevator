# Angel Elevators

Modern, award-winning website for Angel Elevators - showcasing luxury elevator systems with advanced 3D animations and immersive scroll experiences.

## 🚀 Features

- **Immersive 3D Animations**: GSAP-powered scroll animations that simulate elevator movement
- **Interactive Floor Navigation**: Real-time floor tracking with elevator-style controls
- **Video Slider**: YouTube shorts showcase with touch swipe support
- **Responsive Design**: Perfect experience across all devices
- **Glassmorphism UI**: Modern, futuristic design aesthetic
- **Performance Optimized**: Fast loading and smooth animations

## 🛠️ Technologies

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid)
- JavaScript (ES6+)
- GSAP (GreenSock Animation Platform)
- ScrollTrigger

## 📁 Project Structure

